# Portfolio Optimization and Backtesting

## Overview

This project implements quantitative portfolio construction techniques using modern portfolio theory.

The objective is to construct an optimal portfolio, evaluate its risk-return characteristics, and test its out-of-sample performance.

## Methods Implemented

- Monte Carlo Portfolio Simulation
- Mean-Variance Optimization (Markowitz Model)
- Efficient Frontier Construction
- Capital Market Line (CML)
- Out-of-Sample Portfolio Backtesting
- S&P 500 Benchmark Comparison

## Methodology

1. Download historical stock prices.
2. Calculate annualized returns, volatility, and Sharpe ratios.
3. Simulate thousands of possible portfolios.
4. Optimize portfolio weights using the Sharpe ratio.
5. Evaluate performance on out-of-sample data.
6. Compare results against the S&P 500 benchmark.
