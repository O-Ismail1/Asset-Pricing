# CAPM and Fama French Models

## Overview

This project implements classical asset pricing models to analyze the relationship between asset returns and systematic risk factors.

The analysis applies CAPM and Fama-French factor models using historical stock returns and evaluates factor exposures over time.

## Models Implemented

- Capital Asset Pricing Model (CAPM)
- Fama-French Three-Factor Model
- Fama-French Five-Factor Model
- Rolling Beta Estimation
- Fama-MacBeth Cross-Sectional Regression

## Methodology

1. Download historical stock prices f.
2. Calculate monthly stock returns.
3. Estimate regression models.
4. Compare model performance.



## Results

The analysis compares CAPM and Fama-French models based on regression statistics and examines how systematic risk exposures change over time.
