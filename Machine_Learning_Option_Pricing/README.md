# Machine Learning for Option Pricing

## Overview

This project compares machine learning models with the Black-Scholes model for pricing European call options.

The objective is to evaluate whether machine learning algorithms can approximate option prices generated by the Black-Scholes formula.

## Methodology

1. Download historical stock prices from Yahoo Finance.
2. Generate  option prices using the Black-Scholes model.
3. Train machine learning models to predict option prices.

## Models

The following models are compared:

- Support Vector Regression (SVR)
- Random Forest
- Neural Network
- XGBoost

## Evaluation Metrics

Model performance is evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
- Absolute Pricing Error

## Results

The results compare machine learning predictions using pricing error analysis and model evaluation metrics.
